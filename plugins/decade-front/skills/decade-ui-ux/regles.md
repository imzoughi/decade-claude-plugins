# Règles d’affinage (synthèse impeccable + UI/UX Pro Max)

- Rythme : une échelle d’espacement (4/8 px) ; plus d’air entre sections qu’entre éléments d’une section.
- Hiérarchie : 1 seul H1 ; titres en police d’affichage grasse ; 3 niveaux de taille maximum par écran.
- Lisibilité : 45 à 75 caractères par ligne ; interligne 1,4–1,6 pour le texte.
- Cartes : hauteurs égales dans une grille ; actions alignées en bas ; images au même ratio.
- États : chaque élément interactif a survol, focus visible, actif, désactivé.
- Mouvement : 150–250 ms, courbes douces ; respecter `prefers-reduced-motion`.
- Couleur : l’accent sert l’action principale ; pas plus d’une action primaire par zone.
- Formulaires : labels visibles, erreurs sous le champ, aide contextuelle.
- Mobile : cibles ≥ 44 px, pas de débordement horizontal, contenus prioritaires en premier.
- À éviter : ombres lourdes, dégradés gratuits, texte en majuscules de style, icônes de sources mélangées, emojis.
